# GreenTech MVP Sostenible

## Problema
La web original usaba muchas librerías innecesarias (Bootstrap, jQuery, etc.), lo que hacía que pesara mucho.

## Solución
He eliminado todo eso y he usado solo HTML, CSS y JavaScript básico.

## Mejora
- La web carga más rápido
- Consume menos datos
- Usa menos batería

## Impacto ambiental
Menos datos = menos energía = menos contaminación

## Referencias
[1] W3C Web Sustainability Guidelines, 2023  
[2] Green Software Foundation, 2024
